# Model Resources

This directory contains resources related to the SIGNX Machine Learning model.

## Directory Structure
- `labels/`: Contains class mapping files (e.g., `classes.json`).
- `weights/`: Destination for the compiled model file (`signx_model.h5`).
- `preprocessing/`: Documentation on the computer vision preprocessing steps.

## Setting up the Model
The actual trained weights are not stored in source control. 

1. Obtain the `signx_model.h5` file from the project Google Drive.
2. Save it to `model/weights/signx_model.h5`.
